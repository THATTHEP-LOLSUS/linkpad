**ซาวด์บอร์ดที่เล่นเสียงจากลิงก์ได้เลย — ไม่ต้องมีคลังเสียงสำเร็จรูป**
วางลิงก์ YouTube หรือ TikTok (หรือเลือกไฟล์ในเครื่อง) แล้ว LinkPad จะเล่นเสียงนั้นเข้า *ไมค์เสมือน*
เพื่อนของคุณจะได้ยินใน **Discord** และ **เกม**

## ความสามารถ

- **ลิงก์เป็นเสียง:** วางลิงก์ โหลดเสียงครั้งเดียวแล้วเก็บในคลัง (ใช้ออฟไลน์ได้หลังจากนั้น)
- **รองรับ:** YouTube, TikTok (ทั้งลิงก์เต็มและลิงก์สั้น `vm.tiktok.com`), ไฟล์ในเครื่อง
  (mp3 wav ogg m4a flac aac opus webm mp4 mkv) ส่วนเว็บอื่นที่ [yt-dlp](https://github.com/yt-dlp/yt-dlp)
  รองรับ เช่น SoundCloud อาจใช้ได้แต่ไม่รับประกัน
- **โหมดการเล่น:** เล่นครั้งเดียว · วนเพลงนี้ · เล่นต่อทั้งคลัง · วนทั้งคลัง
- **คลังเสียง:** เปลี่ยนชื่อเพลง (✎ หรือคลิกขวา) ลบ ก่อนหน้า/ถัดไป
- **ควบคุมสด:** ระดับเสียง (0–500%) ความเร็ว (0.5×–2×) เบส โหมดลั่นสุด (Earrape) แถบเลื่อนเวลา และเวลาที่เล่นถึง / ความยาวทั้งหมด
- **ส่งเสียงสองทางพร้อมกัน:** เข้าไมค์เสมือนให้เพื่อนได้ยิน และเข้าหูฟังให้คุณได้ยินด้วย
- **หน้าจอ ไทย / English:** สลับภาษาได้ที่ปุ่มมุมขวาบน (จำค่าที่เลือกไว้ให้)
- **ปุ่มลัดทั่วระบบ** (ใช้ได้ตอนอยู่ในเกม): `F7` ก่อนหน้า · `F8` เล่น/พัก · `F9` หยุด · `F10` ถัดไป

## หลักการทำงาน

```
YouTube / TikTok / ไฟล์ ──► yt-dlp + ffmpeg ──► LinkPad ──► CABLE Input ──► CABLE Output ──► Discord / เกม (เป็น "ไมค์")
                                                      └──► หูฟังของคุณ (ฟังเอง ถ้าเปิด)
```

LinkPad ไม่ได้ฝังตัวเข้าไปใน Discord หรือเกม แต่เล่นเสียงเข้า "สายเสียงเสมือน" (เช่น
[VB-CABLE](https://vb-audio.com/Cable/)) แล้วคุณเลือกปลายอีกด้านของสายเป็นไมค์

## สิ่งที่ต้องมี

- Python 3.9 ขึ้นไป
- สายเสียงเสมือน **Windows:** [VB-CABLE](https://vb-audio.com/Cable/) (ฟรี)
- ออกแบบสำหรับ Windows เป็นหลัก ส่วน macOS/Linux ยังไม่ได้ทดสอบ (ต้องใช้อุปกรณ์เสมือนอย่าง BlackHole หรือ PulseAudio null sink และปุ่มลัดบน Linux ต้องใช้สิทธิ์ root)

## ติดตั้งและรัน

```bash
git clone https://github.com/THATTHEP-LOLSUS/linkpad.git
cd linkpad
python -m pip install -r requirements.txt
python -m linkpad
```

บน Windows ดับเบิลคลิก `setup.bat` (ติดตั้ง) แล้ว `run.bat` (เปิดโปรแกรม) ก็ได้
ffmpeg แถมมากับ `imageio-ffmpeg` ไม่ต้องติดตั้งเพิ่ม

## ตั้งค่าครั้งแรก

1. ติดตั้ง **VB-CABLE** แล้วรีสตาร์ทเครื่อง
2. ใน LinkPad: **ส่งเสียงเข้า** = `CABLE Input`, **ฟังเองที่** = หูฟัง/ลำโพงของคุณ (หรือ *ปิด*)
3. ใน Discord / เกม: ตั้ง **Input Device (ไมค์)** เป็น `CABLE Output`
4. ใน Discord → Voice & Video: **ปิด** Noise Suppression, Echo Cancellation, Automatic Gain Control
   และลด Input Sensitivity ให้ไว (หรือใช้ Push-to-Talk) ไม่งั้นเพลงจะถูกตัด
5. ถ้าอยากพูดพร้อมเล่นเสียง ให้ใช้ [VoiceMeeter](https://vb-audio.com/Voicemeeter/) รวมไมค์จริงกับสายเสียง

## วิธีใช้

1. วางลิงก์แล้วกด **Enter** (หรือ **เพิ่ม + เล่น**) หรือกด **เพิ่มไฟล์**
2. คลิกชื่อเพลงเพื่อเล่น เลือกโหมดการเล่นจากแถบใต้ปุ่มควบคุม
3. เปลี่ยนชื่อเพลงด้วย ✎ หรือคลิกขวา ลบด้วย ✕

ความเร็วเปลี่ยนแบบเทป คือเร็วขึ้นแล้วเสียงสูงขึ้นด้วย

## ข้อมูลเก็บที่ไหน

คลังเสียงและไฟล์ที่โหลดเก็บที่ `%APPDATA%\LinkPad` (Windows) หรือ `~/.config/LinkPad`
ภาษาที่เลือกก็บันทึกไว้ที่นี่ด้วย (`settings.json`) ตั้งตัวแปรแวดล้อม `LINKPAD_HOME` เพื่อเปลี่ยนโฟลเดอร์ได้ การลบเพลงจะลบไฟล์แคชของเพลงนั้นด้วย
(ไฟล์ที่เพิ่มจากในเครื่องของคุณเองจะไม่ถูกแตะ)
ตอนเล่นเพลงจะถูกถอดรหัสเก็บในแรม (ประมาณ 11 MB ต่อนาที) วิดีโอยาวมากจึงกินแรมเยอะ

## โครงสร้างโปรเจ็ค

```
linkpad/
├── linkpad/
│   ├── __main__.py    # จุดเริ่มต้น (python -m linkpad)
│   ├── gui.py         # หน้าต่าง คลังเสียง ปุ่มควบคุม (customtkinter)
│   ├── audio.py       # เอนจินเล่นเสียง: อุปกรณ์ ความเร็ว ระดับเสียง เบส
│   ├── media.py       # โหลดด้วย yt-dlp + ถอดรหัสด้วย ffmpeg + ข้อความ error
│   ├── library.py     # คลังเสียง (JSON) เปลี่ยนชื่อ/ลบ
│   ├── playlist.py    # ตรรกะโหมดการเล่น (เพลงต่อไปคืออะไร)
│   ├── i18n.py        # ข้อความหน้าจอ ไทย / English
│   ├── config.py      # ค่าคงที่ โฟลเดอร์ข้อมูล การตั้งค่าที่บันทึกไว้
│   └── assets/        # โลโก้และไอคอนหน้าต่าง
├── tests/             # unit test (ไม่ต้องมีการ์ดเสียง)
├── .github/workflows/tests.yml
├── requirements.txt · pyproject.toml · run.bat · setup.bat
└── README.md · README.th.md · LICENSE
```

## แก้ปัญหา

| อาการ | ลองทำ |
|---|---|
| ลิงก์ TikTok / YouTube โหลดไม่ได้ | `python -m pip install -U yt-dlp` (เว็บเปลี่ยนระบบบ่อย) |
| ลิงก์เป็นส่วนตัว/ต้องล็อกอิน | ไม่รองรับ |
| เพื่อนไม่ได้ยิน | Input ของ Discord เป็น `CABLE Output` หรือยัง ปิด Noise Suppression / AGC แล้วหรือยัง |
| ใน LinkPad ไม่ได้ยินเสียงเลย | เลือกหูฟังในช่อง **ฟังเองที่** และเช็กแถบระดับเสียง |
| ขึ้นข้อความ "ไม่พบ VB-CABLE" | ติดตั้ง VB-CABLE แล้วรีสตาร์ทเครื่อง |

## เกี่ยวกับโปรเจ็คนี้ / พัฒนาร่วมกับ AI

โปรเจ็คนี้ **พัฒนาร่วมกับผู้ช่วย AI ([Claude](https://www.anthropic.com/claude) ของ Anthropic)**
ไม่ได้เขียนเองทั้งหมด เจ้าของโปรเจ็คเป็นคนคิดไอเดีย บอกว่าโปรแกรมควรทำอะไร ลองรัน และแจ้งปัญหาที่เจอ
ส่วนโค้ด เทสต์ และเอกสารส่วนใหญ่เขียนโดย Claude ผ่านการคุยโต้ตอบกันไปมา

เทสต์อัตโนมัติครอบคลุมตรรกะของโปรแกรม (คลังเสียง โหมดการเล่น การคำนวณเสียง) แต่ไม่ครอบคลุมทุกสภาพแวดล้อมจริง
(การ์ดเสียงต่างรุ่น เวอร์ชันของ Discord/เกม หรือการเปลี่ยนระบบของ YouTube/TikTok) ควรอ่านโค้ดก่อนนำไปใช้จริง
และเปิด issue ถ้าเจอปัญหา

## ข้อควรระวัง

LinkPad ดาวน์โหลดเสียงจากลิงก์ที่คุณให้ ไว้ใช้ส่วนตัว คุณต้องรับผิดชอบเรื่องข้อกำหนดการใช้งานของแต่ละแพลตฟอร์มและลิขสิทธิ์เอง
การเล่นเสียงดังมาก/โหมดลั่นสุดอาจทำให้หูเสียและรบกวนผู้อื่น โปรดใช้อย่างมีสติ
